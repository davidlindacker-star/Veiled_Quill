# Veiled Quill Invitation Site

Kleine statische Einladungssite für die Fourth Convocation.

## Lokal testen
Einfach `index.html` im Browser öffnen.

## Gäste ändern
In `script.js` das Array `guests` anpassen.

Wichtig: Die Zugangsdaten sind bei dieser rein statischen Variante nicht wirklich geheim. Wer den Quellcode untersucht, kann sie finden. Für eine private Geburtstagseinladung ist das normalerweise ausreichend.

## Deployment
Die Dateien können direkt in ein GitHub-Repository gelegt und über GitHub Pages veröffentlicht werden.
